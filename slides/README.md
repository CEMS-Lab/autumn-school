# Lecture slides

Open [the 44-slide PDF](phast_autumn_school_2026.pdf) for the lecture.
The presentation uses a white background, LaTeX equations and original
Matplotlib figures. The [speaker notes](beamer_speaker_notes.md) provide
timings, questions, activity transitions and scientific qualifications.

For editing, extract [the self-contained source ZIP](phast_latex_sources.zip),
or work in [source/slides](../source/slides/README.md) in the complete course
folder. Its README explains how to regenerate figures and compile the deck.

The [teaching schedule](../TEACHING_SCHEDULE.md) covers three two-hour sessions.
The [execution report](../EXECUTION_REPORT.md) distinguishes the actual PhAST
forward run from the small inverse and machine-learning teaching models.
