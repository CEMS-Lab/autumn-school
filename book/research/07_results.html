The coincidence check intentionally records a zero separating gradient. A passing test reproduces that stationary configuration. Separating coincident particles requires a prescribed perturbation or another tested geometry rule.

Reproduce and inspect#

Download the experiment script and retained arrays and checks. The figure renderer only reads retained results. The workflow source uses LaTeX/TikZ. The rendering receipt records input, generator and figure hashes with the plotting-library version.

python lab.py --output teaching_results.json

NumPy and PyTorch are required. Research executions for this project use HPC. The script exits unsuccessfully if any declared teaching check fails. The source SHA-256 stored in the result file is checked by the renderer.

What this evidence establishes#

The tests verify geometry behaviour, quadrature, a smooth linear-solve derivative, simple optimisation and observation models, and a corrected linear prediction. Verifying an entire fracture trajectory additionally requires its specific source, observation rule, history updates and forward/adjoint checks. The application chapter sets out those separate experiments.

A pocket chain rule.

Let q = θ2 and L = ½(q − 4)2. At θ = 1, which way does the loss decrease locally?

Follow the derivative

dL/dθ = (q − 4) · 2θ = −6. A sufficiently small positive change in θ decreases the loss. The gradient points uphill; a descent step goes against it.
