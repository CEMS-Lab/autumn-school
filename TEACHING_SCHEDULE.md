# Six-hour teaching route

Three 120-minute sessions, each including a ten-minute break. Teaching times
include explanation, predictions, discussion and exercises; computation itself
is measured separately and must remain under five minutes per notebook.

| Session time | Session A: the fracture model |
| --- | --- |
| 00–10 | Opening prediction and optional notebook 00 teaser; briefly connect its ambiguity to the course questions. Slides 1–3 are an alternative introduction, not extra time. |
| 10–25 | Crack representations and the distinction between models and algorithms. |
| 25–45 | Fracture energy, regularisation and AT1/AT2. |
| 45–60 | Degradation functions and their derivatives. |
| 60–70 | Break. |
| 70–90 | Damage profiles, mesh resolution, initiation, propagation and branching. |
| 90–100 | Staggered updates and convergence. |
| 100–114 | Time integration, nonlinear iteration and matrix-free actions. |
| 114–120 | Tensor fields and physical locations. |

| Session time | Session B: a run and its derivatives |
| --- | --- |
| 00–10 | Verify setup and locate the notebooks and configuration. |
| 10–33 | Geometry, mesh, boundary conditions and configuration. |
| 33–55 | Notebook 01: compare damage fields, response and numerical checks. |
| 55–60 | Change one input and explain the difference. |
| 60–70 | Break. |
| 70–85 | Tensor operators and a defined computational graph. |
| 85–97 | Notebook 02: analytic, autograd and finite-difference derivatives. |
| 97–110 | Notebook 03: inverse observations, recovery and limitations. |
| 110–120 | Save a reproducible experiment and review its evidence. |

| Session time | Session C: learning around numerical solvers |
| --- | --- |
| 00–18 | Data splits, model inputs and the small MLP. |
| 18–45 | Notebook 04: held-out fields, training, save and reload. |
| 45–60 | Compatible model swaps and metadata. |
| 60–70 | Break. |
| 70–90 | Notebook 05: proposal, bounds, residual assessment and correction. |
| 90–105 | DAgger-style data aggregation; reference-label cost and evaluation. |
| 105–115 | Architecture choices and how to read a larger research example. |
| 115–120 | Contributions, recap and next steps. |

Use the presentation's speaker notes for slide-specific prompts and transitions.
If setup is incomplete, learners can still predict and interpret the executed
notebook pages while a colleague helps prepare their environment.
