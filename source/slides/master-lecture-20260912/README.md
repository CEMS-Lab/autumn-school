# PhAST UKACM Autumn School 2026 — master deck

`PhAST_UKACM_Autumn_School_2026_Master.pptx` is the single editable entry-point deck.  It is organised in three teaching sections:

1. Phase-field fracture and the PhAST workflow.
2. Differentiability, sensitivities, and inverse questions.
3. Learning interfaces and hybrid simulation.

The 90-slide authoring scaffold remains the extended lecture outline.  The short autodiff primer and animated solver introduction are modular inserts, retained so that the presenter can use or omit them without duplicating the core narrative.  This deck uses the ECCOMAS/WCCM references for whitespace, one-idea-per-slide pacing, and equation–visual alignment only; conference images are not embedded here.

The damage visuals preserve the computed diffuse field.  Where a sharp visual cue is useful, the deck labels it as a high-damage core (`d ≥ 0.95`), rather than representing it as a sharp-crack result.
